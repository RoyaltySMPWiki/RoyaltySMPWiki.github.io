# Royalty SMP Kingdoms

Static website for the Royalty SMP Kingdoms Minecraft server: rules, nations, tokens, classes and more.

No build step and no dependencies. It is plain HTML, CSS and JavaScript.

## Publish on GitHub Pages

1. Create a new repository on GitHub and upload **everything in this folder** (`index.html`, `style.css`, `script.js`, `images/`, `.nojekyll`).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
4. After a minute your site is live at `https://<your-username>.github.io/<repo-name>/`.

## Preview locally

Open `index.html` in a browser, or run `python3 -m http.server` in this folder.
